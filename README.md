# 🚀 Exploring Odoo

This repository contains the **source code** featured on the **[Exploring Odoo YouTube channel](https://www.youtube.com/@exploring-odoo)**.
Each branch corresponds to specific videos — make sure you’re on the **right branch** for the code you’re following.

To properly use this code, it’s **essential** to watch the related YouTube video:
