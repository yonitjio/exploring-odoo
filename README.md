# Exploring Odoo

This repository contains the source code and projects featured on the [Exploring Odoo](https://www.youtube.com/@exploring-odoo) YouTube channel.

> **Note:** Please ensure you are on the correct branch for the specific tutorial or project you are looking for.

## The Nuido Branch

This branch is dedicated to `Nuido`-related modules. **Nuido** is a library designed to create node-based user interfaces for Odoo.

### Project Status: No Longer in Active Development

Having served its purpose as a pioneer in creating multi-purpose, node-based user interfaces using pure Owl, Nuido is no longer in active development. 

My hope is that this codebase serves as an inspiration for the Odoo developer community, showcasing the potential of pure Owl and encouraging the development of even more sophisticated node-based interfaces for Odoo.

### A Note on Nuido 2 and Nuido 3

I'm still working on my projects, though there's currently no plan to release them publicly. In the meantime, you can explore what they can do through the videos on my YouTube channel.

Nuido 2 is no longer actively developed, as I'm now focusing on Nuido 3.
